Here's what I built:

📊 Power BI-style interactive dashboard
📄 4-page professional PDF report
🤖 Python (scikit-learn) + RFM clustering model

The result? 6 distinct customer segments:

👑 Champions — high spend, high loyalty → VIP rewards
💎 Loyal Customers → referral programmes
⚠️ At-Risk → win-back campaigns
🌱 New Customers → onboarding journeys
💤 Hibernating → re-engagement sequences
❌ Lost → final reactivation or sunset

Key insights from the data:
→ Champions (17%) generate 43% of total revenue
→ At-Risk customers have dropped 10% in 5 months
→ New Customers over-index on Fashion & Beauty
→ Loyal customers spend 4x more than New ones

Tools I used:
✅ Python · scikit-learn · K-Means clustering
✅ RFM analysis (Recency, Frequency, Monetary)
